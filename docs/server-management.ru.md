# 🖥️ Руководство пользователя: Управление сервером Amnezia VPS

Добро пожаловать в личный кабинет управления вашим виртуальным сервером (VPS). На этой странице собрана вся необходимая информация для контроля работы сервера, параметры подключения, а также пошаговые инструкции для новичков.


---

## ⚙️ 1. Параметры подключения (Ваши данные)

Эти данные необходимы для настройки VPN-клиентов, подключения к серверу через консоль или передачи в сторонние программы.

> ⚠️ **ВАЖНОЕ ПРАВИЛО БЕЗОПАСНОСТИ:** Эти данные являются строго конфиденциальными. Никогда не передавайте их третьим лицам. Сотрудники технической поддержки никогда не попросят ваш пароль.

*   🌐 **IP-Адрес сервера:** `0.0.0.0` *(Основной адрес вашего сервера в сети интернет)*
*   👤 **Имя пользователя:** `root` *(Главный администратор системы с полными правами)*
*   🔑 **Пароль доступа:** `XXxxXX2026` *(Сгенерирован автоматически при создании сервера)*

## 🛠️ 2. Доступные действия в панели управления

Вы можете управлять физическим состоянием вашего сервера прямо из личного кабинета с помощью кнопок:

*   🚀 **Включить (Power On):** Запускает операционную систему сервера, если он был выключен.
*   🛑 **Выключить (Shutdown):** Посылает сигнал операционной системе на безопасное завершение всех процессов и отключение питания. Рекомендуется использовать именно этот вариант.
*   ⚡ **Принудительное выключение (Power Off):** Моментально обесточивает сервер. Используйте только в том случае, если сервер завис и не реагирует на обычную команду `Shutdown`.
*   🔄 **Перезагрузить (Reboot):** Выполняет быструю перезагрузку сервера для обновления конфигурации или применения настроек.
*   🔑 **Сбросить пароль (Reset Password):** Стирает текущий пароль администратора и генерирует новый. **Внимание:** перед нажатием этой кнопки сервер необходимо обязательно выключить с помощью команды `Shutdown`.
*   💳 **Продлить услугу (Renew Service):** Быстрый переход на платежный шлюз для пополнения баланса и продления срока аренды.

## ⚠️ 3. Безопасность и решение критических проблем

Мы заботимся о стабильности вашей работы, поэтому в панели действуют ограничения, созданные для защиты ваших данных.

### 🚨 Что делать, если статус сменился на «Broken State»?
Если в графе состояния сервера вы видите надпись **Broken State**, либо если сервер по какой-то причине перестал включаться и не реагирует на нажатие кнопок `Power On` / `Reboot`:
1. Не пытайтесь многократно нажимать кнопки управления — это может усугубить ошибку внутри виртуального контейнера.
2. Сразу же **напишите тикет в нашу службу технической поддержки**. Наши инженеры вручную проверят состояние ноды (физического оборудования) и восстановят доступ в кратчайшие сроки.

### 🔒 Почему нельзя изменить IP-адрес самостоятельно?
В целях безопасности всех клиентов хостинга, функция самостоятельной смены IP-адреса в панели заблокирована. Это предотвращает случайную потерю связи с сервером и защищает от мошеннических действий.
*   Если вам по объективным причинам необходимо заменить IP-адрес (например, из-за блокировок со стороны провайдеров), **обратитесь в службу поддержки**.
*   Специалисты проведут быструю верификацию вашего аккаунта и произведут замену адреса вручную ради вашей безопасности.

## 📖 5. Подробная инструкция по подключению к серверу (для новичков)

Если вам нужно установить на сервер дополнительное ПО, настроить прокси или проверить конфигурацию, вам понадобится подключиться к текстовой консоли сервера по протоколу **SSH**.

### Шаг 1: Откройте терминал на вашем ПК
*   **Если у вас Windows:** Нажмите на клавиатуре комбинацию клавиш `Win + R`, в открывшемся окошке введите `cmd` и нажмите Enter. Перед вами откроется черное окно командной строки.
*   **Если у вас macOS или Linux:** Найдите через поиск приложений программу **«Терминал»** (Terminal) и запустите её.

### Шаг 2: Введите команду подключения
В открывшемся терминале введите следующую команду (замените `0.0.0.0` на ваш реальный IP-адрес из раздела 1) и нажмите Enter:
```bash
ssh root@0.0.0.0
```

### Шаг 3: Подтвердите безопасность
При самом первом подключении компьютер спросит вас, доверяете ли вы этому серверу:
> *Are you sure you want to continue connecting (yes/no/[fingerprint])?*
*   Напечатайте слово **`yes`** на английском языке и нажмите Enter.

### Шаг 4: Введите пароль доступа
Система попросит ввести секретный ключ: `root@0.0.0.0's password:`
1. Скопируйте ваш пароль (`XXxxXX2026`).
2. Нажмите правой кнопкой мыши в окне терминала (или нажмите комбинацию клавиш `Shift + Insert`), чтобы вставить пароль.
3. Нажмите Enter.
4. ⚠️ **ВАЖНО:** Когда вы вставляете или пишете пароль в терминале, **на экране ничего не появляется (ни символов, ни звездочек, ни точек)**. Это встроенная защита Unix-систем. Пароль при этом успешно вставляется — просто нажмите Enter.

## 🗲 6. Шпаргалка по базовым командам

После успешного входа вы увидите приветствие системы. Вот основные команды, которые могут вам пригодиться:

*   **Полное обновление системы до актуальной версии:**
    ```bash
    apt update && apt upgrade -y
    ```
*   **Проверить, сколько свободного места осталось на диске:**
    ```bash
    df -h
    ```
*   **Запустить диспетчер задач для просмотра нагрузки на процессор и память:**
    ```bash
    htop
    ```
    *(Чтобы выйти из этого режима, нажмите на клавиатуре английскую букву `Q`)*
*   **Принудительно перезагрузить сервер прямо изнутри системы:**
    ```bash
    reboot
    ```
*   **Безопасно разорвать соединение с сервером и закрыть терминал:**
    ```bash
    exit
    ```
