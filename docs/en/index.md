## Where to start

1. Go to the **[client area](https://my.amnezia.host)** — it's where you get your server details (IP, login, password) and can manage the server (reboot, reinstall the OS).
2. Connect to the server over SSH — the **[Quick Start](/en/commands)** section walks you through it, even if you've never used a terminal before.
3. Install the **[AmneziaVPN](https://amnezia.org)** app and set up your VPN in three steps — see **[VPN Setup](/en/vpn-setup)**.
4. If something goes wrong, check the **[FAQ](/en/faq)** or message **[Telegram support](https://t.me/amnezia_hosting_bot)**.

::: tip One server, the whole toolkit
Besides a VPN, the same server can run secure file storage or a site on the Tor network — all through the same AmneziaVPN app.
:::
