# 📊 Установка и настройка веб-панели 3X-UI

**3X-UI** — это продвинутая графическая веб-панель для управления вашим VPN-сервером на базе ядра Xray-core. Она позволяет в один клик создавать ключи доступа, настраивать современные протоколы (VLESS, Shadowsocks, Trojan) и следить за расходом трафика клиентов.

---

### 🚀 Шаг 1. Установка панели на VPS

Подключитесь к вашему серверу по SSH и выполните официальный скрипт автоматической установки:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/mhsanaei/3x-ui/master/install.sh)
```

В процессе установки консоль предложит вам настроить параметры безопасности. **Рекомендуем согласиться (`y`)** и задать кастомные данные:
1. **Username** — введите ваш логин администратора панели.
2. **Password** — введите сложный пароль.
3. **Port** — укажите любой случайный порт (например, `2083` или `8443`) вместо стандартного, чтобы защитить панель от сканеров.

---

### 🌐 Шаг 2. Вход в веб-интерфейс

1. Откройте ваш браузер и перейдите по адресу:
   `http://IP_АДРЕС_ВАШЕГО_СЕРВЕРА:УКАЗАННЫЙ_ПОРТ`
2. Введите логин и пароль, созданные на Шаге 1.

---

### 🛡️ Шаг 3. Создание подключения (Inbound) с VLESS Reality

Протокол **VLESS + Reality** — лучший выбор для обхода блокировок, так как он маскирует ваш трафик под обычное посещение разрешенного веб-сайта.

1. В левом меню панели перейдите в раздел **"Inbounds"** (Подключения) и нажмите кнопку **"Add Inbound"**.
2. Заполните основные настройки:
   * **Remark:** Любое название (например, `VLESS-Reality`).
   * **Protocol:** Выберите `vless`.
   * **Port:** Оставьте случайный или укажите `443` (для идеальной маскировки).
3. Включите переключатель **Reality**.
4. Настройте параметры маскировки:
   * **uTLS:** Выберите `chrome` или `firefox`.
   * **Dest / SNI:** Укажите сайт для маскировки (панель предложит варианты автоматически, например, `dl.google.com:443` и `dl.google.com`).
   * Нажмите кнопки **"Get New Cert"** и **"Get New Seed"** для автоматической генерации приватных ключей безопасности.
5. Нажмите кнопку **"Create"** внизу окна.

---

### 👥 Шаг 4. Добавление пользователей и выдача ключей

Внутри каждого подключения (Inbound) вы можете генерировать независимые ключи для разных людей или устройств.

1. Напротив созданного подключения нажмите **"Operations"** → **"Add Client"**.
2. Вы можете настроить индивидуальные лимиты (необязательно):
   * **Total Flow:** Лимит трафика в Гб (например, `100` для ограничения лимита пользователя).
   * **Expiry Time:** Срок действия ключа (дата отключения).
3. После сохранения нажмите на иконку **"QR-код"** или **"Ссылка"** напротив имени пользователя.
4. Скопируйте полученную ссылку вида `vless://...` и импортируйте её в клиентское приложение.

---

### 📱 Рекомендуемые приложения (Клиенты)

Сгенерированные панелью ссылки и QR-коды поддерживаются всеми современными VPN-клиентами:

| Платформа | Рекомендуемое приложение |
| :--- | :--- |
| **Android** | Hiddify, v2rayNG, Nekobox |
| **iOS (iPhone)** | FoXray, Streisand, Shadowrocket, V2Box |
| **Windows / macOS** | Hiddify, NekoRay, v2rayN |

---

### ⚙️ Полезные команды для терминала
Если вам потребуется сбросить настройки или перезапустить панель через SSH-консоль, просто введите в терминале команду:
```bash
3x-ui
```
Откроется удобное текстовое меню управления, где вы сможете сбросить забытый пароль, изменить порт или перезапустить службу.
