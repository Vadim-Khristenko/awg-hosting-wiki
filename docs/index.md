## Что входит в сервер

Тарифы Amnezia Hosting рассчитаны на стабильную работу VPN с подключением **до 10 устройств** одновременно:

| Ресурс | Значение |
| :--- | :--- |
| **Процессор** | 1 × 2,2 ГГц |
| **Оперативная память** | 1 ГБ |
| **Диск** | 10 ГБ SSD |
| **Трафик** | Безлимитный (канал до 100 МБ/с) |
| **ОС по умолчанию** | Ubuntu 22.04 LTS (Debian 12 — по запросу) |
| **Оплата** | Банковские карты (Visa / Mastercard), Freekassa |

::: tip Разворачивается за 1 минуту
Установите приложение [AmneziaVPN](https://amnezia.org) и разверните личный VPN, защищённое хранилище документов или сайт в сети Tor всего за пару минут — сложные консольные команды не требуются.
:::
